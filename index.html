Daily Dev Hacks Uploader

Daily Dev Hacks is a short-form video channel with 30-second programming tips, Linux tricks and AI developer tools.

The Uploader is the creator's own tool. Each day it renders that day's tip as a vertical video and, with the creator's permission, sends it to the creator's TikTok inbox as a draft through the TikTok Content Posting API (video.upload). The creator then opens TikTok, reviews and edits the draft, and posts it manually. The tool never publishes anything by itself.
